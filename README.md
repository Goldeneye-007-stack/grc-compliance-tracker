# 📊 GRC Compliance Tracker – ISO 27001 & NIST 800-53

This project tracks and manages governance, risk, and compliance (GRC) activities aligned with major cybersecurity frameworks like ISO 27001 and NIST SP 800-53. It includes control mapping, policy tracking, audit planning, and implementation oversight.

---

## 🎯 Objective

Help organizations stay compliant and audit-ready by mapping internal SOPs and policies to external framework requirements, tracking ownership, and ensuring regular review.

---

## 🧰 What's Included

- 📁 `grc-policy-mapping.xlsx`: Tracks each policy/SOP against ISO/NIST controls
- 🧩 Columns include: Framework, Control ID, Summary, Owner, Frequency, Status
- 🗂 Evidence locations (e.g., SharePoint, audit logs, Jira, etc.)

---

## 📎 Supported Frameworks

| Framework    | Focus |
|--------------|-------|
| ISO 27001    | Information Security Management |
| NIST 800-53  | Security and Privacy Controls |
| (Add more as needed) | SOC 2, HIPAA, CIS, etc. |

---

## 🧠 Example Use Case

- Map your IT SOPs to ISO 27001 control domains
- Assign owners for control execution and evidence collection
- Track frequency of tasks (monthly, quarterly, annually)
- Prepare for internal or external audit reviews

## 💡 Lessons Learned

- Having mapped SOPs ensures quick audit readiness
- Evidence should be centralized (SharePoint, Confluence, etc.)
- Framework overlap allows reuse of controls across ISO/NIST
